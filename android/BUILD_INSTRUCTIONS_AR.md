# بناء تطبيق «أرحنا بها» للأندرويد

هذا المشروع يغلّف تطبيق الويب داخل تطبيق أندرويد قابل للتثبيت.
المرحلة الحالية (١): واجهة التطبيق كاملة تعمل كتطبيق مثبّت.
المراحل التالية ستضيف: الأذان في الخلفية والشاشة مقفلة + ويدجت الشاشة الرئيسية.

## الطريقة الأسهل — Android Studio (مجاني)

1. نزّل وثبّت **Android Studio** من: https://developer.android.com/studio
   (أثناء التثبيت يحمّل Android SDK تلقائياً — عدة غيغابايت، مرّة واحدة.)
2. شغّل Android Studio → **Open** → اختر مجلد `android` من هذا المستودع.
3. انتظر انتهاء **Gradle Sync** (يحمّل الاعتماديات أول مرة فقط).
4. من القائمة: **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
5. عند الانتهاء يظهر إشعار صغير فيه **locate** — اضغطه ليفتح مجلد الملف:
   `app/build/outputs/apk/debug/app-debug.apk`
6. انقل `app-debug.apk` إلى هاتفك (كابل أو تيليغرام/بريد)، افتحه،
   اسمح بـ«تثبيت من مصادر غير معروفة»، ثم ثبّت.

## الطريقة البديلة — سطر الأوامر

1. ثبّت **Android command-line tools** و **JDK 17**.
2. أنشئ ملف `android/local.properties` يحوي مسار SDK، مثال:
   `sdk.dir=C\:\\Users\\<اسمك>\\AppData\\Local\\Android\\Sdk`
3. من مجلد `android` نفّذ:
   ```
   gradlew.bat assembleDebug
   ```
4. الملف الناتج: `app\build\outputs\apk\debug\app-debug.apk`

## ملاحظات
- أول بناء يحتاج إنترنت (يحمّل أدوات Gradle و Android). الأبنية التالية أسرع.
- نسخة **debug** كافية للتثبيت الشخصي والمشاركة اليدوية (لا تحتاج توقيعاً خاصاً).
- حجم التطبيق كبير نسبياً لأنه يضمّ ١٧ أذاناً صوتياً بالداخل ليعمل دون إنترنت.
